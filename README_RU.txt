1. Сохраните резервную копию прежних файлов.
2. Распакуйте содержимое архива прямо в public_html с заменой файлов.
3. index.html должен находиться прямо в public_html, не во вложенной папке.
4. Права файлов: 644.
5. Обновите страницу сайта: Ctrl+F5.

Сайт статический: Node.js, PHP и база данных не требуются.
