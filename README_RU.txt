Версия 1.15 — иллюстрация памятника на первом экране.

1. Распакуйте архив.
2. Откройте репозиторий timur-marketing на GitHub.
3. Add file → Upload files. Загрузите содержимое архива в корень репозитория, без внешней папки.
4. Нажмите Commit changes.
5. Дождитесь успешного обновления GitHub Pages в Actions.

Обязательно загрузите index.html и новый файл ulan-ude-lenin.png. Остальные файлы также включены для полного размещения.
